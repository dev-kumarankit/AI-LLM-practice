# Interview Preparation

## Weekly interview structure

- One Python coding challenge.
- One TypeScript or Node.js coding challenge.
- One SQL challenge.
- One Spark or Kafka scenario.
- One RAG or LangGraph architecture question.
- One AWS architecture scenario.
- One system-design review.
- One incident-debugging exercise.

## Required answer format

1. Clarify requirements and constraints.
2. Explain the data and control flow.
3. Present an initial design.
4. Identify failure modes and tradeoffs.
5. Add security, observability and operational requirements.
6. Measure and validate the design.

## Final evaluation

The learner should be able to independently design, implement, debug and operate the desired architecture, not merely list technologies.
