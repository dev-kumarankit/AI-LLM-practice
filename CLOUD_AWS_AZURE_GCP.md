# Cloud Engineering — AWS, Azure and GCP

## Primary path

AWS is the required deep focus. Azure and GCP should be introduced through realistic architecture comparisons and representative service mappings.

## Required topics

- AWS IAM, STS, Cognito, OIDC, VPC, S3, Lambda, API Gateway, SQS, SNS, EventBridge, RDS, DynamoDB, Redshift, OpenSearch, Bedrock, KMS, Secrets Manager, CloudWatch and X-Ray.
- Azure AI Foundry, Azure OpenAI, Functions, AKS, Blob Storage, Entra ID and data services.
- GCP Vertex AI, Cloud Run, Cloud Functions, BigQuery, Pub/Sub, GKE and Cloud Storage.
- Networking, shared services, security, cost and operational tradeoffs.

## Required exercises

- Design a secure network and identity boundary.
- Compare serverless, container and managed-service choices.
- Deploy a service with infrastructure as code.
- Add logs, traces and cost allocation.
- Test rotation, recovery and least-privilege behavior.
- Create an architecture decision for a provider-specific service.
