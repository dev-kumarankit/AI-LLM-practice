# Advanced Node.js and TypeScript

## Core progression

1. Event-loop internals and concurrency.
2. Worker threads, streams and backpressure.
3. Memory management, profiling and performance.
4. Advanced TypeScript: mapped, conditional, generic, branded and discriminated types.
5. REST, GraphQL, gRPC and WebSockets.
6. Express, NestJS, Fastify and BFF boundaries.
7. Monorepos, package architecture and shared contracts.
8. Idempotency, distributed transactions and stream processing.
9. API load testing and secure integrations.

## Required exercises

- Build a TypeScript API with strict typing and runtime validation.
- Compare Node event-loop behavior with Python asyncio.
- Handle backpressure in a stream and verify timeout behavior.
- Define a typed API contract consumed by the Python service.
- Add authorization, request tracing and idempotency keys.
- Exercise a retry and dead-letter policy.
