# AI and Machine Learning Foundations

## Required progression

1. Linear algebra, calculus, probability and optimization.
2. Regression, classification, feature engineering and evaluation.
3. NumPy, Pandas, Polars and scikit-learn.
4. Neural networks, backpropagation and PyTorch.
5. Attention, transformers, tokenization and embeddings.
6. Hugging Face models and datasets.
7. Fine-tuning, LoRA, quantization and inference optimization.
8. Model serving, monitoring and reproducibility.

## Learning rule

Teach when to prompt, retrieve, fine-tune or train. Do not treat all model access as a model training problem.

## Required exercises

- Implement linear regression and gradient descent from first principles.
- Build a supervised classification pipeline with leakage checks.
- Train a small PyTorch model with reproducible seeds.
- Compare a pretrained model with a retrieval-only solution.
- Benchmark inference latency, memory and cost.
- Record a model card, dataset version, prompt version and evaluation result.
