# Advanced Data Engineering

## Required progression

1. Advanced SQL, indexes, locking, isolation and query plans.
2. ETL versus ELT, data contracts and schema evolution.
3. PySpark, partitions, shuffles, skew and execution plans.
4. Kafka, consumer groups, offsets and delivery semantics.
5. CDC, Debezium, outbox and reconciliation.
6. Airflow, dbt, data quality, lineage and recovery.
7. Parquet, Delta/Iceberg, lakehouses and warehouse design.
8. Governance, privacy, masking and access control.

## Required exercises

- Write and optimize SQL with window functions.
- Build a Spark transformation and inspect the plan.
- Process a Kafka event with replay and deduplication.
- Implement CDC reconciliation and schema compatibility.
- Build idempotent Airflow and dbt tests.
- Compare Redshift and Snowflake using real operating constraints.
- Reconcile source and target row counts and business totals.
