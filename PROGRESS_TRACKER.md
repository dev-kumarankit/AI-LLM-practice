# Progress Tracker

## Principle

A week is complete only when the learner has:

- A Git commit.
- Automated tests with a recorded result.
- A short learning summary.
- A design, security, performance or reliability artifact.
- A known limitation and next action.

## Weekly record template

| Field | Required evidence |
|---|---|
| Week | Number and topic |
| Objectives | Three measurable outcomes |
| Code | Commit or pull request |
| Tests | Command, pass/fail count, failure behavior |
| Measurement | Benchmark, latency, query plan or quality result |
| Security | Authorization, injection or secret-handling test |
| Architecture | ADR, diagram or tradeoff note |
| Learnings | Reasoning, decision and duration |
| Next week | Dependency and open issue |

## Phase checklists

### Phase I — Weeks 1–8

- [ ] Python package and type checks are reproducible.
- [ ] FastAPI service with tests is available.
- [ ] SQL and query-plan exercise is complete.
- [ ] Profiling and concurrency evidence are recorded.
- [ ] Architecture decisions are documented.

### Phase II — Weeks 9–16

- [ ] Retrieval baseline is measurable.
- [ ] Citation and permission behavior is tested.
- [ ] LangGraph state and recovery are tested.
- [ ] Prompt-injection and tool-authorization cases are recorded.
- [ ] Agent evidence includes latency, cost and safety.

### Phase III — Weeks 17–26

- [ ] CDC and replay behavior are demonstrated.
- [ ] Spark plan and performance evidence exist.
- [ ] Data quality and lineage tests are passing.
- [ ] Lakehouse and warehouse architecture is documented.
- [ ] Recovery and backfill runbooks exist.

### Phase IV — Weeks 27–34

- [ ] Model experiments are reproducible.
- [ ] Algorithms, prompts and model versions are tracked.
- [ ] Offline evaluation gates exist.
- [ ] Inference and model cost are measured.
- [ ] Safety and prompt-injection tests are passing.

### Phase V — Weeks 35–42

- [ ] Distributed consistency behavior is tested.
- [ ] Observability and SLO evidence exist.
- [ ] IaC and deployment are reproducible.
- [ ] AWS integration and security tests pass.
- [ ] Load and chaos results are recorded.

### Phase VI — Weeks 43–48

- [ ] All three projects integrate.
- [ ] Security, reliability and cost evidence exist.
- [ ] Architecture decisions and runbooks are complete.
- [ ] Final demo and scorecard are available.
