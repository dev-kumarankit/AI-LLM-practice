# MLOps and LLMOps

## Required progression

1. Dataset and model versioning.
2. Experiment tracking with MLflow.
3. Model registry and release controls.
4. Model serving and batch versus online inference.
5. Drift, monitoring, prompt and evaluation versioning.
6. Human evaluation and regression gates.
7. Cost, latency, A/B testing and rollback.
8. Responsible AI and incident ownership.

## Required exercises

- Create a reproducible experiment pipeline.
- Run an evaluation suite before and after a change.
- Track prompts, datasets, model versions and tool outputs.
- Add a model-serving API with metrics and rollback.
- Compare deployment strategies and operational cost.
- Record a model release decision and failure case.
