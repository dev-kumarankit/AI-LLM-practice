# DevOps, Platform Engineering and SRE

## Required progression

1. Git, branching, CI/CD and release strategy.
2. Linux, Bash, Docker and Compose.
3. Kubernetes, Helm, networking and autoscaling.
4. Terraform, AWS CDK and environment isolation.
5. Secrets, artifacts, build security and rollback.
6. OpenTelemetry, Prometheus, Grafana and distributed tracing.
7. SLI/SLO, error budgets, incident response and recovery.
8. Load testing, capacity, disaster recovery and cost optimization.

## Required exercises

- Package and deploy a small service through Docker.
- Build a pipeline with lint, tests, security checks and artifacts.
- Implement an observability configuration and run an incident simulation.
- Validate a Kubernetes deployment with health probes and autoscaling.
- Run a load test and record p50/p95/p99 latency.
- Create a runbook for rollback and backup restoration.
