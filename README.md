## Required operating principle

Every major topic must move through concept, mechanics, example, implementation, tests, failure handling, optimization and architecture tradeoffs.

## Project sequence

1. Secure enterprise RAG and agentic AI.
2. Real-time enterprise data engineering.
3. Cloud-native AI/ML intelligence platform.

## Notebook and source policy

Do not fabricate benchmark results. Every test, latency, source-to-target reconciliation and cost estimate must be run and recorded.
