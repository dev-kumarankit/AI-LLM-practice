# System Design and Distributed Systems

## Required progression

1. Data structures, algorithms and complexity.
2. Operating systems, networking and protocol behavior.
3. Databases, consistency, transactions and replication.
4. Queues, backpressure, retries and event-driven architecture.
5. Partitioning, sharding, replication and fault tolerance.
6. CAP, consistency models and distributed transactions.
7. Caching, idempotency, DLQs and recovery.
8. Senior-to-staff architecture reviews and production tradeoffs.

## Required design exercises

- Design a retrieval service with caching and tenant filtering.
- Design an event pipeline with ordering, retries and replay.
- Compare synchronous and asynchronous API boundaries.
- Explain a replication and availability failure.
- Select a storage, queue and orchestration pattern.
- Create a number of architectural alternatives and justify the decision.
